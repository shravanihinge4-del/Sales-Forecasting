# SALES FORECASTING

## Project Description
Sales Forecasting is a Machine Learning project that predicts future sales using historical sales data.

## Objectives
- Analyze previous sales data.
- Visualize monthly sales.
- Build a Linear Regression Model.
- Predict future sales for the next 6 months.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Algorithm
Linear Regression

## Dataset
The dataset contains Month and Sales columns.

## Output
The project predicts future sales for the next 6 months and displays the results using graphs.

## Future Enhancement
- Use larger sales datasets.
- Apply advanced Machine Learning algorithms.
- Develop a sales prediction web application.

## Conclusion
The Sales Forecasting project successfully predicts future sales using Linear Regression and historical sales data.
